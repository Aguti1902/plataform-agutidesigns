# lokify-public

Landing pública de **lokify.es** + panel cliente (autoservicio).

Pendiente. Día 1 solo deja el espacio reservado en el monorepo.

Planeado:

- Next.js 15 App Router + Tailwind 4.
- Landing optimizada para conversión por nicho (dentista, fisio, restaurante…).
- Onboarding integrado con Stripe checkout + alta automática en `clientes`.
- Panel cliente con SSO Supabase Auth, métricas mensuales, factura mensual, gestión de dominio.
